# Muhammad Shaheryar — Portfolio

A responsive portfolio website built with HTML, CSS and JavaScript for the Microsoft Front-End Development course.

**Live site:** https://YOUR-USERNAME.github.io/portfolio/

## What's inside

| File | Purpose |
| --- | --- |
| `index.html` | Page structure using semantic elements (`header`, `nav`, `main`, `section`, `figure`, `form`, `footer`) |
| `style.css` | Colours, typography and layout, with media queries at 900px and 680px for tablets and phones |
| `script.js` | Interactivity: mobile menu, "Show the markup" inspector, project filter, active nav link, contact form validation |
| `images/` | SVG illustrations for projects, portrait and favicon |

## Accessibility

- Every content image has descriptive `alt` text; decorative images use `alt=""`
- Skip-to-content link, visible keyboard focus, and `aria-*` attributes on the menu, filters, switch and form errors
- Respects the `prefers-reduced-motion` setting

## Run locally

Open `index.html` in any browser. No build step needed.
